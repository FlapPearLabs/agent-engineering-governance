# 需 owner 决定的 H5 开跑前选项

这些是推荐，不是已批准的协议；当前无授权构建、模型运行或 runs root。来源：`experiments/v1.2/mechanization-gap/experiment-protocols.md` §0、§3、§4，及 `H5_DESIGN_BRIEF.md`。

1. **任务来源**：A 验证 H2 真实任务可串接后使用；B 另选真实历史多步任务。推荐 A 优先做只读适配性检查，不满足依赖/独立 oracle 就 B；禁止虚构可串接。
2. **样本与 episode**：A 每臂 2 个任务、每任务 2 episode；B 按预先功效分析扩样。推荐 B，A 仅为下限而非保证显著性；两臂 episode 数必须相等。
3. **M4 故障**：A 受控杀隔离子进程；B 安全复现真实整个 exec 通道崩溃。推荐 A 且明确其外推限制；B 须先证明安全可复现并单独批准。
4. **closure 的实境**：A 隔离替身模拟 merge/CI；B 在获批专用仓做真实闭环。推荐 A 作机制实验，不能据此声称真实 merge 与 post-merge CI；若要真实证明再选 B 并批准外部操作。
5. **决策阈值与预算**：A 事先指定每个 M1–M3 的统计检验、效应大小、M7 非劣界与总成本上限；B 先小型探索再另行注册正式实验。推荐 B 仅在另获执行授权且探索结果不能混入正式样本后采用；无阈值/有效功效只能 `INSUFFICIENT_EVIDENCE`。
6. **持久证据及信任边界**：A 审批本机持久目录和 worker 不可写的独立链尾锚点；B 使用外部存储。推荐 A，先核对权限与恢复能力；任何新增外部服务/数据源须另批。
7. **P7 与 N7**：A 等 #45 明确承重机制及正负控，再做 H5 自己的复合 gate 控制；B 设计修改使对应质量主张不依赖该 gate。推荐 A；目前没有 N7 结果，不能宣称 P7 已通过。
