# H4 — owner decisions on the open questions

Owner decision (2026-10-29): "按推荐". The decisions below adopt the
recommendations in `OPEN_QUESTIONS.md`. This is **not** a protocol freeze and **not**
authorization to build or run an experiment.

| # | Question | Decision |
|---|---|---|
| Q1 | Task source and oracle rule | **A:** keep the strict rule; collect more real LOW history, with separate authorization for another project. Never invent tasks. The current 3 < 4 eligible tasks leave H4 `PROTOCOL_NOT_STARTABLE`. |
| Q2 | Arm carriers | **A:** pinned deterministic extraction, independently checked source and delivery hashes, isolated homes and a common path; explicit A-layer sources, no fallback. |
| Q3 | Injection classes | **A first:** F-010 hollowed Ruff gate with N7 and exact config/real-path controls; do not claim all defect classes are covered. |
| Q4 | N per arm and power | **B:** specify paired design, effect size, non-inferiority margin, alpha, power and clustering, then calculate N and repeats. The minimum is a feasibility floor only; preserve invalid cells. |
| Q5 | Budget | **A only with separate execution authorization:** separately registered capped exploration followed by a formal budget; set per-run and total caps and record actual charges. Cost is unknown until measured; exploratory data is not formal evidence. |
| Q6 | Independent-review blinding | **A:** isomorphic schemas, masked identifiers, adversarial leak tests and an independent blind-review receipt. If leakage remains, blinding is VOID; unblinded review does not satisfy P4. Exact-SHA independent review remains separate. |
| Q7 | Thresholds and stopping | **B when thresholds or power cannot be justified in advance:** use an exploratory phase and separately preregister a confirmatory protocol. Do not promote exploratory findings as confirmatory. |
| Q8 | Evidence location and controls | **A:** a durable local location outside temporary paths with access, alias and restart verification, plus pinned gate controls. New services or sources need separate authorization. |
